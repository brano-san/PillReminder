# Замечания по вкладке «История» → версия 1.2.3

Дата: 14.09.2026. Пять замечаний после проверки 1.2.2 на устройстве. Статус: **выпущено 15.09.2026** (versionCode 6, схема v5 зафиксирована).

| # | Замечание | Решение |
|---|---|---|
| 1 | Коричневый цвет частично пропущенных дней | `heatColor(ratio)`: оттенок HSV от 0° (красный) к 120° (зелёный) ступенями по 20 % выпитого — `heatStep()` (тест `HeatStepTest`). Легенда переписана. |
| 2 | Цифра «1» чёрная на цветной клетке | Текст на любой цветной клетке — белый; зависимость цвета текста от доли убрана. |
| 3 | Историю прошлых дней можно править | Кнопки «Выпито / Пропустить / Вернуть» у прошлого дня спрятаны за карандашом над лентой + диалог «Изменить прошлый день?». Режим сбрасывается при смене дня; повторный тап по карандашу выключает его. Сегодня — как раньше. |
| 4a | Воскресенье сжалось в столбик | Дни недели — `weight(1f)` каждый, `maxLines = 1, softWrap = false`; стрелки и «к сегодня» — 36 dp вместо 48. |
| 4b | «Запланирован-о на 07:07» | Кнопки приёма — отдельной строкой под текстом, текст занимает всю ширину карточки. |
| 4c | «Настрой…» в нижней панели | Подпись вкладки 10 sp без разрядки, `TextOverflow.Visible` (M3 `NavigationBarItem` внутренние отступы не отдаёт, ширина у пяти вкладок и так поровну). |
| 5 | «Сегодня отличный день…» на прошлом дне | Фраза показывается только когда выбран сегодняшний день. |

## Шестой заход: правки по пятому (15.09.2026)

| # | Замечание | Решение |
|---|---|---|
| 1 | «другое…» ссылкой не как у «штук за приём» | Везде чипом в сетке: число приёмов — 3 колонки, «другое…» на две (`weight(2f)`); промежуток — 3×2 и «другое…» строкой. `OtherLink` и ключи `otherNumberChip/customIntervalChip` удалены. |
| 2 | «По часам» — сразу три времени | При выборе режима `clockTimes = [09:00]`, `timesPerDay = 1`; остальные — кнопкой «Добавить время». |
| 3 | Тап по метке превью листает, но не прокручивает | `Fact(text, step, anchor)`; `scrollStates` на каждый шаг, `anchors` через `onGloballyPositioned` на `SectionCard`/спойлере; `goTo(step, anchor)` ставит `pendingAnchor`, `LaunchedEffect` ждёт координату на новой странице и прокручивает (якорь `ADVANCED` раскрывает спойлер). |
| 4 | «Во весь экран» включён без разрешения | `LaunchedEffect(refresh)` на экране звука: `fullScreenAlarm && !canUseFullScreenIntent` → тумблер и настройка выключаются. Строка статуса и ключи `fsiOk/fsi14Note` удалены. |
| 5 | Порог запаса: ввод числа, чипы-прибавки | Между «−» и «+» — `OutlinedTextField` с цифровой клавиатурой (1–100, ошибка вне диапазона); чипы `AssistChip` «+3 +5 +10 +20» по центру прибавляют к текущему. |
| 6 | Схема дня появляется с пролагом после «Подъёма» | Две причины: `wakeUpLocked` писал подъём и приёмы отдельно (главный видел один узел, карточка не показывалась, потом появлялась) — теперь `db.withTransaction`; и `animateScrollTo` при первом показе — теперь первый показ `scrollTo`, анимация только при изменениях. |
| 7 | Превью дня в календаре не как схема дня | `DayPreview` рисует `DayTimeline` из `buildTimelineNodes` (в `JournalState` добавлен `doseInfoById`); `autoScroll` только для сегодня. |
| 8 | Поиск по заметкам | `filterNotes`: все слова запроса, поля название/описание/текст/теги, `lowercase`, «ё»→«е», `normalizeSearch`. Тест `NoteSearchTest`. |
| 10 | «В этот день приёмов не было» у будущего дня | Будущий день без узлов — превью не рисуется вовсе. |

## Восьмой заход — перед релизом (15.09.2026)

| # | Замечание | Решение |
|---|---|---|
| 1 | Лаг при частых переходах «превью → блок → превью» | Две причины: `onGloballyPositioned` десяти карточек писал в `mutableStateMapOf` на каждом кадре (теперь запись только при изменении) и пейджер пересобирал тяжёлый шаг 2 при каждом переходе (теперь `beyondViewportPageCount = 2`: все шаги в композиции, координаты блоков известны заранее). |
| 2 | Форма выпуска и единицы дозировки не сеткой | `ChipGrid(3)`: семь форм + «другая…» на две клетки; восемь единиц + «другая…» = 3×3. |
| 3 | Ряды пресетов далеко, колонки близко | У чипов M3 зона касания 48 dp при высоте 32 → между рядами 8 + 16 dp. `ChipGrid` задаёт `LocalMinimumInteractiveComponentSize = 32.dp`, отступы 6 dp по обеим осям. |
| 4 | Долгое нажатие на карточку: заголовок без тела | Тело всегда: «Что сделать с таблеткой?» + кнопка «Изменить»; далее «Пропустить»/«Отложить»/«Порядок» по ситуации; «Дублировать» и «Удалить» — кнопки диалога. |

Не проверено на устройстве: реальная ширина подписи «Настройки» в 10 sp на самом узком экране, вид ступеней цвета в тёмной теме,
возврат тумблера «Во весь экран» после системного экрана на Android 14+ (эмулятора под рукой нет), скорость бегущей строки при
крупном шрифте, реальная задержка появления схемы дня после «Подъёма» на слабом устройстве, попадание пальцем по чипам без
48-dp зоны касания.
