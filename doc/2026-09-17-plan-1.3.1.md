# План 1.3.1: закрыть UX-ревью 1.3.0

Версия 1.3.1 (versionCode 9). Источник — [UX-ревью](2026-09-17-ux-review-1.3.0.md), номера совпадают.
Схема БД не меняется. Правило прежнее: логика — в чистую функцию с тестом.

## A. Неверная запись в историю

- [x] 1. «Выпить всё, что пора» считает и отмечает одним правилом; просроченные больше 2 ч в «пора» не попадают. Тест `TakeAllTest`
- [x] 2. Карточка показывает актуальный приём, просроченные выносятся отдельной строкой с действиями
- [x] 3. Журнал считает «прошлым днём» по дню цикла, а не по календарю
- [x] 4. Клетка сегодня краснеет только после двух часов просрочки. Тест `HeatMarksTest`
