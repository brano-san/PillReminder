# План 1.3.0: закрыть всё ревью 1.2.4

Версия 1.3.0 (versionCode 8). Источник — [ревью 1.2.4](2026-09-16-code-review-1.2.4.md), номера пунктов ниже совпадают с его нумерацией.
Схема БД не меняется (v6), формат бэкапа поднимается до 7. Правило: каждая правка с логикой получает чистую функцию и тест.

## A. Критично

- [x] 1. Курс «по часам» не обрывается в последний день: планирование и деактивация разведены (`fixedCourseOver`), деактивация только по сегодняшнему дню и через `deactivateLocked`. Тест `FixedCourseTest`
- [x] 2. Импорт проверяет, что файл — бэкап приложения (`Backup.looksLikeBackup`, маркер `app`), иначе `NotABackupException` и своё сообщение. Тест `BackupGuardTest`
- [x] 3. «Сон» переспрашивает, когда есть неотмеченные приёмы, и говорит их число. Тест на подсчёт `bedtimeDropCount`
- [x] 4. Правка истории прошлого дня: связанные таблетки не планируются в прошлое, `shiftFollowing` не двигает приёмы в будущее, отметка пишет время плана, «день закрыт» не уведомляет о прошлом. Тест `HistoryEditTest`
- [x] 100. В журнале у прошлого дня показывается только осмысленное действие: выпито → «Вернуть», пропущено → «Вернуть», ожидает → «Выпито» и «Пропустить». Тест `JournalActionsTest`

## B. Безопасность

- [x] 5. Замок перезакрывается при уходе с экрана (`LockState`, сброс в `onStop`), состояние не переживает смерть процесса
- [x] 6. Ошибки биометрии обрабатываются: текст ошибки на экране замка и кнопка «Повторить»
- [x] 7. Уведомления о приёме `VISIBILITY_PRIVATE` + `setPublicVersion` с обезличенным текстом
- [x] 8. Режим конфиденциальности действует на остаток, визиты, трекеры и виджет
- [x] 9. Разрушительные действия с экрана блокировки требуют разблокировки (`setAuthenticationRequired`), «Выпито» остаётся быстрым
- [x] 10. Облачный бэкап только при сквозном шифровании (`disableIfNoEncryptionCapabilities`), база исключена из `device-transfer`-переноса на чужое устройство
- [x] 11. `BootReceiver` реагирует только на свои четыре действия
- [x] 12. Мелочи: `promptDeviceLock` fail-closed, `FLAG_SECURE` при включённом замке, проверка схемы `photoUri` при импорте, экранирование формул в CSV, лишние разрешения убраны. Тесты `CsvEscapeTest`, `PhotoUriTest`

## D. Несостыковки

- [x] 17. Счётчик и действие «Выпить всё, что пора» считают по одному предикату (`Planner.isDueNow`). Тест `TakeAllTest`
- [x] 18. Крестик у времени «по часам» удаляет время; дублирующий ряд убран
- [x] 19. Под заблокированной кнопкой мастера видна причина и ссылка «Исправить». Тест `BlockReasonTest`
- [x] 20. Экран корреляций считает по правилам отчёта (`Report.includeDose`, те же фильтры трекеров)
- [x] 21. Отчёт: выбранная таблетка без приёмов печатается строкой «нет приёмов», фильтр действует на заметки, у всех разделов есть верхняя граница периода. Тест `ReportRangeTest`
- [x] 22. «Отложить» на группе откладывает всю группу
- [x] 23. Полноэкранный будильник обновляется по `onNewIntent`
- [x] 24. Напоминание о просроченном приёме назначается один раз (`remindAt` фиксируется). Тест `OverdueRetryTest`
- [x] 25. «Подъём» и «Начать новый день» не трогают приёмы «по часам»
- [x] 26. Переключение режима расписания возвращает прежние значения
- [x] 27. «По часам» переживает перевод стрелок (`LocalDate.atTime(...).atZone`). Тест `FixedTimesDstTest`
- [x] 28. «Отложить» доступна, когда ожидание еды истекло
- [x] 29. Дата конца приёма в каталоге совпадает с последним днём курса. Тест `CourseEndTest`
- [x] 30. Приём, ждущий «Еда», не считается пропуском в отчёте. Тест в `ReportFilterTest`
